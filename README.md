# Nav8 Browser — Releases

Download the latest version of Nav8 from the [Releases](https://github.com/sandman66666/nav8-releases/releases) page.

**Nav8** is the first browser where AI doesn't just chat — it acts. Browse, search, fill, click, buy. Human and machine, side by side.

## Installation

1. Download the latest `.dmg` from [Releases](https://github.com/sandman66666/nav8-releases/releases/latest)
2. Open the DMG and drag **Navigator.app** to your Applications folder
3. Launch Navigator

The app auto-updates via Sparkle — you'll be notified when new versions are available.

## Requirements

- macOS 13.0 (Ventura) or later
